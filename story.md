# Fahrtenbuch
Ich möchte eine Fahrtenbuch app erstellen, die ein paar erweiterte features mit sich bringt
## Stack
PWA, React, daten werden in der ersten release am client gespeichert, kein backend
## features
### hauptbildschirm
openseamap mit bootsposition. die zurückgelegte strecke soll eingezeichnet werden. gps position soll alle paar sec geloggt werden
es soll oben und/oder unten noch eine statusleiste angezeigt werden: zb aktueller kurs...
### fahrtebuch einträge
über ein einfaches menü sollen die verschiedenen kacheln für einträge ins fahrtenbuch angezeigt werden. 
diese sollen entsprechend groß sein, damit man sie gut lesen und treffen kann, wenn man in fahrt ist. wsl werden wir das auf mehrere screens aufteilen müssen. verwende icons
oft benutzte einträge sollen vorgereiht werden, zb "wende", "neuer kurs xy". 
je log eintrag soll bekannte telemetrie vor-eingetragen werden, zb "neuer kurs" soll den aktuellen gps kurs vor-eintragen
## export
mach einen vorschlag. zb pdf oder csv, via app teilen?
## zurücksetzen
man soll auch alle daten löschen können
